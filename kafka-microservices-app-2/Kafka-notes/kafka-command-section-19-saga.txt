Step 3: Build the project in order. Common -> Order Service -> Product Service -> -> Payment -> Credit Card service with 'mvn clean install'


Step 4: Run the project in order Order service -> Product service applic -> Payment ->  Credit card processor service

Step 5: Hit the request from postman

    a) Create product by calling the below curl and after prodcut created pass the reponse product id to the order service curl.
        curl --location 'http://localhost:8081/products' \
        --header 'Content-Type: application/json' \
        --data '{
            "name": "iphone 6",
            "price": 1200,
            "quantity": 10
        }'

    b)   
        curl --location 'http://localhost:8080/orders' \
        --header 'Content-Type: application/json' \
        --data '{
            "productId": "cdc89100-828b-4ffe-b16d-6187a6152626",
            "productQuantity": 1,
            "customerId": "cdc89100-828b-4ffe-b16d-6187a6152000"
        }'  

    c)  Get the order history by passing the order id from b) response
            curl --location --request GET 'http://localhost:8081/orders/c1b920bd-2e89-461a-9573-024c606c602e/history' \
            --header 'Content-Type: text/plain' \
            --data '{
                "productId": "6d75b683-fa36-406f-9c7b-f5d863394007",
                "productQuantity": 1,
                "customerId": "6d75b683-fa36-406f-9c7b-f5d863390000"
            }'
